# Sales & Revenue Analysis Dashboard

## Internship Project
This project was completed as part of my Data Analytics Internship at Thiranex.

## Project Overview
The project analyzes sales data to identify revenue trends, top-performing products, sales representatives, categories, and cities.

## Dataset
The dataset contains:
- Date
- Product
- Category
- Sales Representative
- City
- Number of Units
- Price
- Amount

## Analysis Performed
- Sales and revenue analysis
- Product-wise sales analysis
- Category-wise sales analysis
- Sales representative performance
- City-wise sales analysis
- Month-wise sales trends
- Pivot table analysis
- Interactive dashboard with filters

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Dashboard

## Project Result
The dashboard provides a visual summary of sales performance and helps identify important revenue trends and business insights.
